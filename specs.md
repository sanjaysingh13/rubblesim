# Engineering Specification: RubbleSim Web Enhancements
**Target Tech Stack:** Three.js, React Three Fiber (R3F), @dimforge/rapier3d-compat (WASM Single-Threaded), Vite.

## 1. Project Context & Philosophy
RubbleSim Web is a 100% client-side, browser-based Urban Search & Rescue (USAR) simulator. It procedurally generates structures, simulates structural collapses, and algorithmically identifies survival voids using ray-marching. 

The next phase of development transitions the simulation from a passive collapse model into an interactive tactical trainer. The goal is to blend civil engineering physics (material failure, dead/live loads, shoring) with intuitive user interactions (breaching, cutting, lifting).

---

## 2. Structural Engineering Physics Core

### A. Failure Mechanics (Civil Engineering Rules)
*   **Reinforced Concrete (RC):** Must be modeled as composite structures. Concrete handles compression; steel rebar handles tension.
*   **Failure Profiles:** 
    *   *Pancake:* Column loss causes floor-on-floor stacking.
    *   *Soft-Story:* Ground floors buckle under upper-tier weight.
    *   *Progressive:* Failure of one member sequentially unloads onto and breaks adjacent members.

### B. Mathematical Formulas for Real-Time Evaluation
The physics engine must evaluate stress states to trigger secondary collapses when users interact with the rubble pile:

*   **Load Matrix Calculation:**
    $$W = \int_{A} (D_L + L_L) \, dA$$
    *(Where $D_L$ = dead structural weight, $L_L$ = live load of rescuers/equipment, and $A$ = tributary area).*

*   **Euler Column Buckling (Secondary Collapse Trigger):**
    $$P_{cr} = \frac{\pi^2 E I}{(K L)^2}$$
    *(Where $E$ = elasticity, $I$ = damaged inertia moment, $L$ = length, and $K$ = end-fixity factor).*

## 3. Interactive Feature Implementation Specifications

### Feature 1: Compound Rebar & Slab Cutting
*   **Data Representation:** Represent slabs as collections of contiguous rigid-body fragments linked via `Rapier.FixedJoint` instances. These joints represent reinforcing steel strands.
*   **Cut Interaction:**
    1.  Cast a Three.js `Raycaster` from the user's cursor targeting the sub-mesh or joint position.
    2.  If the tool is a **Saw/Torch**, locate the intersecting joint and remove it using `world.removeImpulseJoint(joint)`.
    3.  If a concrete segment is completely severed, split the parent rigid body into distinct child bodies, copying over the existing `linearVelocity` and `angularVelocity` to preserve physical momentum.

### Feature 2: Pneumatic Lifting Bags
*   **Physics Mechanism:** Use a temporary constraint or apply linear upward vectors to simulate expansion forces.
*   **Implementation Steps:**
    1.  On user placement, detect the contact interface between two overlapping rigid bodies.
    2.  Inject a localized upward force via `body.applyForceAtPoint(forceVector, localPoint, true)`.
    3.  Implement a strict threshold: If $W_{debris} > F_{max\_bag}$, the bag must enter a "stalled" state, requiring the user to shed structural weight or build structural shoring first. Max displacement must cap rigidly at 50 cm.

### Feature 3: Structural Shoring (Stabilization)
*   **Physics Mechanism:** Instantiation of static obstacles that redistribute live loads.
*   **Implementation Steps:**
    1.  Upon placement of a shore (T-shore or lace shore), capture the vector between the ground floor and the sagging overhead slab.
    2.  Instantiate a fixed structural body: `RigidBodyDesc.fixed()`.
    3.  Monitor active contact manifolds via `world.contactsWith(shoreBody)`. Extract the normal impulses to calculate structural load transfer.

## 4. UI/UX Architecture & Vibe-Coding Design Patterns

### A. Real-Time Stress Mapping (Vertex Colors)
To make engineering limits visually intuitive without overwhelming dashboards, use vertex-color feedback loops:
*   Query Rapier joint forces every $N$ frames.
*   Map the current stress fraction ($\text{Stress} / \text{SnapThreshold}$) to a color gradient.
*   Update the Three.js mesh material color dynamically (Linear interpolation from Grey $[0.5, 0.5, 0.5]$ to Red $[1.0, 0.0, 0.0]$).

### B. Interactive HUD Tool Ring Strategy
*   Establish a global state tracking active tool selections (`NONE`, `BREACHING_HAMMER`, `TORCH`, `HYDRAULIC_JACK`).
*   Modify `Raycaster` layers based on the active tool. For example, the `TORCH` only intersects elements tagged with a `rebar` metadata property, preventing false selections.

### C. Enhanced Void Visualization
*   Read data structural bounds generated by the ray-marching pipeline (`verify-hole.mjs`).
*   Render corresponding volumetric bounds in the Three.js scene as a very faint spherical wireframe grid (`opacity ≈ 0.07`, no solid fill) so debris remains clearly readable.
*   If any active rigid body enters or intersects these bounding spaces during a physical shift, trigger a `SURVIVOR_COMPROMISED` event flags.

## 5. Reference Code Implementation Pattern
When generating code modifications for `sim.js` or `main.js`, utilize this non-blocking structural integration pattern:

```javascript
/**
 * Processes rescue tool mechanics and alters the Rapier simulation state.
 * @param {Object} intersectionPoint - The Vector3 intersection point from Three.js raycasting.
 * @param {string} activeTool - The currently equipped tool string indicator.
 * @param {RAPIER.World} rapierWorld - Instance of the active WASM physics engine.
 * @param {THREE.Scene} threeScene - Instance of the active render pipeline.
 */
function applyRescueTool(intersectionPoint, activeTool, rapierWorld, threeScene) {
    const targetBody = identifyBodyAtPoint(intersectionPoint, rapierWorld);
    if (!targetBody) return;
    
    switch(activeTool) {
        case 'TORCH':
        case 'CUTTER':
            // Find and sever nearby structural joints simulating steel rebar failure
            const structuralJoints = findJointsConnectedTo(targetBody, rapierWorld);
            structuralJoints.forEach(joint => {
                rapierWorld.removeImpulseJoint(joint);
                spawnParticleEffect(intersectionPoint, 'sparks', threeScene);
            });
            targetBody.wakeUp();
            break;
            
        case 'HYDRAULIC_JACK':
            // Inject upward mechanical lifting force metrics at specific points
            const liftingForce = { x: 0, y: 15000, z: 0 }; 
            targetBody.applyForceAtPoint(liftingForce, intersectionPoint, true);
            break;
            
        default:
            break;
    }
}
```
